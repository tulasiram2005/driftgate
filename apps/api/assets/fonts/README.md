# Report fonts

Noto Sans Regular and Bold, distributed under the SIL Open Font License 1.1.
License: OFL.txt. Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

Fonts are embedded in PDF reports. Keep this assets directory alongside src and
dist in deployments. Supported glyphs render natively; unsupported scripts and
emoji retain explicit Unicode escapes. This is not universal script coverage.
