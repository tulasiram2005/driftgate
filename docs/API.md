# API

Status: Phase 0 foundation only. Authentication, test cases, runs and sign-off endpoints are not implemented yet.

Phase 2 will introduce versioned REST under `/api/v1`, Zod-derived OpenAPI at `/docs`, consistent error responses, cursor pagination, role and ownership checks. Phase 3 adds idempotent run creation, SSE, timestamped HMAC callbacks and replay protection. No mock successful business endpoints are accepted as completed API work.

Update this document from the actual route contracts in each phase; include method, auth, body, success/error examples and validation details.
